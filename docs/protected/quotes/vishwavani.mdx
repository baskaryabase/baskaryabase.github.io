### Recommended Quotation

* **Apple Developer Program:** ₹9,000/year
* **Google Play Console Account:** ₹2,500 (one-time)
* **Cloud Infrastructure (Server + Storage + 2 TB Data Transfer):** **₹8,000/month**

This is a reasonable figure to quote initially, with the note that infrastructure costs may be revised if usage exceeds 2 TB/month.
